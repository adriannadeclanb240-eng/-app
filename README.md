# 💰 个人账本（Personal Ledger）

一款帮助个人用户记录人民币收支的跨平台桌面记账应用（Windows / macOS）。

数据**完全保存在本地**，不联网、不上传，隐私安全。

## ✨ 功能特性

- **记一笔**：快速记录支出 / 收入，选择「一级分类 + 二级分类」和日期，可填写备注
- **账单明细**：按日期倒序查看所有记录，支持删除单条
- **分类管理**：内置两级分类体系，可自行增、删、改
- **统计图表**：本月分类支出、近 12 个月支出趋势、本月收入 / 支出 / 结余
- **月度预算**：设置每月预算，实时显示已用进度
- **导入 / 导出**：一键导出 / 导入 CSV 文件

## 🧭 分类体系

内置一套「一级大类 → 二级小类」的两级分类：

- **支出**：餐饮、交通、购物、居住、娱乐、医疗健康、教育、人情往来、通讯、其他（共 10 大类）
- **收入**：工资、理财、红包、兼职、其他收入（共 5 大类）

所有分类均可在「分类管理」页自由增删改。

## 🛠 技术栈

| 环节 | 技术 |
|---|---|
| 桌面框架 | Electron |
| 界面 | React + TypeScript |
| 构建 / 打包 | electron-vite + electron-builder |
| 图表 | Recharts |
| 数据存储 | 本地 JSON 文件（无需数据库） |

## 🚀 快速开始

**环境要求**：需要先安装 [Node.js](https://nodejs.org/)（建议 18 及以上）。

```bash
# 1. 安装依赖
npm install

# 2. 启动开发版（会自动弹出应用窗口，实时预览）
npm run dev
```

## 📦 打包安装包

```bash
# Windows：生成 .exe 安装包
npm run build:win

# macOS：生成 .dmg 安装包（需在 Mac 电脑上运行）
npm run build:mac
```

打包产物位于 `dist/` 目录。

## 💾 数据存储与隐私

- 所有账目保存在本机一个 `ledger.json` 文件中（位于系统用户数据目录，可用记事本直接打开查看）
- **不联网、不上传**，隐私安全
- 金额以「分」为单位、用整数存储，避免浮点数误差
